Connect to GitHub

This portal saves changes directly to GitHub so Vercel redeploys automatically. You need a GitHub Personal Access Token with Contents: Read & write permission on the LilCheetoz/SharonHartwellwebsite repo.

How to create a token:
  1. Go to github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Click Generate new token
  3. Under Repository access choose Only select repositories → pick SharonHartwellwebsite
  4. Under Permissions set Contents → Read and write
  5. Generate and paste the token below
